# Autonomous Drone Inspection of Offshore Wind Farms
## Università degli Studi di Roma La Sapienza - Planning and Reasoning course project - a.y. 2025/26

This project models an autonomous drone responsible for inspection an offshore wind farm composed of several turbines and a base station for the drone.
The objective is to generate a plan that allows the drone to inspect all turbines and safely return to the base station while managing energy consuption and operational constraints.
Both PDDL and IndiGolog language has been used to modelize the problem and study different aspects related respectively to:

* classical planning (PDDL)
* logical reasoning and reactive execution (IndiGolog)


### Prerequisites

* ENHSP-20 Planner (or later version)
* SWI-Prolog (install with apt command or clone the official repo)
